Debugging Checklist:

  1. Test 1 - If this doesn't work, the TravellerMap API might not support overlay circles in your browser
  2. Test 4 - If you don't see a HUGE circle, the API isn't working at all
  3. Test 5 - If circles appear when zoomed in but not at scale=32, it's a zoom/scale issue
  4. Tests 2 & 3 - If these don't work but Test 1 does, the coordinates (-93, -25) are wrong

What to Report Back:

For each test above, note:

  • ✅ "I see circles" or ❌ "No circles visible"
  • If circles appear, describe where they are relative to hexes
  • Try zooming in/out to see if circles only appear at certain zoom levels
